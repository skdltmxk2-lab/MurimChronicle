## 공통 렌더러

React·오프라인 감사·코칭 인쇄의 보기 파서를 공유한다. 제목 뒤 빈 줄과 진술 사이 빈 줄, ㉠㉡, 수식형 보기 제목, 빈칸 `(가)개` 오인식을 보강했다. 일반 조건 박스에는 보기 제목을 강제로 붙이지 않고, 선지는 박스 자동 감지에서 제외한다. 명확한 별도 발문·결론은 박스 밖에 보존한다.

수식 길이가 짧아도 좁은 화면에서 넘칠 수 있으므로 인라인·블록 수식 모두 필요한 경우 가로 스크롤이 가능하다. 수식의 양끝을 확인할 수 있도록 내부 너비도 보존한다. 모호한 문장은 휴리스틱으로 재작성하지 않는다.

## DB 적용과 재실행

문항 56개와 저장 시험 13개를 검증 후 갱신했고, 출제 제외 문항의 시험 사본 6개를 제거했다. 데일리 961행의 메타데이터가 적용 전후 같음을 확인했다. 기존 학생 응시 기록과 점수에는 쓰기 작업을 하지 않았다. 자체 시험 스냅샷이 없는 레거시 응시가 관련 시험을 참조하는지도 검사했으며 충돌은 0건이었다.

`scripts/content_review/apply_reviewed_batch.mjs`는 기본 읽기 전용이다. 명시적인 private 변경안·고정 ID/해시 목록·출력 폴더를 요구한다. 전체 내용 해시와 변경 시각, 필드별 이전값을 확인하고 백업한 뒤 문항의 변경 시각과 시험의 PostgreSQL xmin으로 경합을 막는다. 각 요청 전에 intent를 기록하며, 응답 유실로 자기 쓰기의 버전을 증명하지 못하면 자동 덮어쓰기 대신 명시적인 복구 필요 상태로 남긴다. 전체 배치가 단일 DB 트랜잭션이라는 보장은 하지 않는다.

검증된 native 적용 영수증은 `scripts/question-audit-20261102-b01/receipt.json`에 보존한다. 원문·백업·이미지 데이터·시험 식별자·학생정보·인증정보는 Git에 넣지 않는다.

```sh
npm run test:content-review
node scripts/content_review/apply_reviewed_batch.mjs --patches /private/final_patches.json --scope /private/mapping.json --out /private/apply
# 검토된 변경을 반영하려면 같은 명령에 --apply, 재조회 검증은 --verify
```

검증: 렌더 회귀·실제 React SSR 비교·운영 빌드 통과, 수정 적용기 로컬 통합 테스트 18개 통과, 문항·시험 사본 재조회 확인.
