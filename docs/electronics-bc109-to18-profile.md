# BC109C TO-18 배치 가능성 및 조건부 프로필 설계

조사일: 2026-11-04. 결론은 **현재 BC109C의 `mounting: "external"`을 유지**하는 것이다. 전기적 E/B/C와 SPICE 모델을 안다는 사실만으로 무성형 빵판 삽입이 가능해지지는 않는다. 이 문서는 제조사 도면의 치수에서 확인할 수 있는 사실, 그 사실에서 계산한 결과, 아직 검증되지 않은 앱 배치안을 구분한다. 코드·카탈로그·실물은 변경하지 않았다.

## 실제로 읽은 근거

이전 조사에서 사용자 제공 `generalNPN_BC109.pdf`를 렌더링한 아래 두 PNG를 확인했다. 현재 지정 원본 폴더와 workspace에서는 PDF 파일 자체를 찾지 못했으므로 **이번 확인은 보존된 제조사 문서 페이지 이미지에 대한 확인**이다. 원PDF를 다시 열었다고 기록하지 않는다.

- `tmp/bc109-p2.png`: Philips Semiconductors, *BC107; BC108; BC109*, Product specification, 1997 Sep 03, p2. 핀표와 simplified outline.
- `tmp/bc109-p5.png`: 같은 문서 p5. SOT18/13 package outline, European projection, 치수표, outline issue date 97-04-18.

두 그림에는 학생 이름·학번 등 개인 자료가 포함되지 않는다. 다른 제조사의 BC109/TO-18 그림을 이 제품의 핀맵 근거로 대체하지 않았다. 웹의 검색 요약은 도면의 top/bottom view를 잘못 설명할 수 있어 방향 판정 근거로 사용하지 않았다.

## 무성형 2.54 mm 격자 삽입이 안 맞는 이유

원도면 좌표를 리드 원 중심 기준으로 정규화하면 다음과 같다. 좌표축 방향은 아래 거리 계산에 영향을 주지 않는다.

```text
r = a/2 = 1.27 mm
E = (0, -r)
B = (r,  0)
C = (0, +r)

|E-C| = 2r = 2.54 mm
|E-B| = |B-C| = sqrt(2)*r ≈ 1.796 mm
```

2.54 mm 정사각 격자의 서로 다른 구멍 사이 거리는 `2.54*sqrt(m²+n²)`이며 최소2.54 mm이다. 따라서1.796 mm인 두 리드 간격을 유지하면서 세 리드를 모두 다른 구멍에 꽂는 정확한 회전·평행이동은 없다. `a=2.54`라는 숫자만 보고 `three` 직선 프로필로 바꾸는 것은 잘못이다. 제조사 공차를 근거로 사용자가 다리를 변형하지 않아도 맞는다고 보장할 수 없다.

또한 **기하학적으로 꽂히는 것과 전기적으로 분리되는 것은 다르다.** 현재 보드에서 A~E 또는F~J의 같은 번호 열은 내부 연결되어 있다.2×2 네 구멍 중 세 구멍을 차지하는 작은L자 배치는 한쪽 영역에서 최소 두 리드가 같은 열을 공유한다. E/B/C가 서로 다른 net이면 그 배치는 단락이다. 원래 캔보다 큰 삼각형으로 무조건 늘리기만 하는 방식도 이 연결 규칙을 검사해야 한다.

## 조건부 프로필 후보 — 제품의 기본 형상이 아님

추후 실제 성형 조건을 검증한다면, 최소한 서로 다른 세 열을 사용하는 **특정 성형 배치**를 명명해서 지원할 수 있다. 예를 들어 세 net가 독립인 일반 NPN에 대해 다음처럼 세 열을 쓰는 삼각형이다.

```text
조건부 개념 예시 — 위에서 본 구멍 좌표, 자동 적용 금지

           열 n       n+1       n+2
행 C       E(1)                 C(3)
행 D                  B(2)

E-C: 5.08 mm, E-B/B-C: 약3.592 mm
세 핀 모두 같은 보드·같은 A~E 영역이지만 서로 다른 연결 열
```

이 예시는 원래 리드 간격을 두 배로 벌린 구멍 패턴이며 **Philips가 제공하거나 승인한 성형 치수는 아니다.** 원도면의 방향을 윗면으로 변환해 E를 왼쪽/C를 오른쪽/B를 아래쪽에 둔 경우와 일치하도록 탭 방향도 함께 정해야 한다. 핀을 교차시켜 억지로 번호 순서를 맞추는 설계는 사용하지 않는다. 표시하는 탭 방향은 원본 투영 변환을 검토한 뒤 확정하고, 단순히 기존TO-92 그림에 탭만 붙이지 않는다.

이 프로필을 쓸 수 있다는 판정에는 아래 조건이 필요하다.

1. 실제 부품이 확인한 Philips BC109C/SOT18 핀맵과 일치하고, 탭·세 리드·캔 연결을 식별할 수 있다.
2. 실제 리드 길이와 성형 상태가 지정 패턴에 맞는다. 도면은 허용 굽힘 반경·성형 공정·누적 굽힘 허용 횟수를 주지 않으므로 그것을 임의 숫자로 만들어 안내하지 않는다.
3. 핀 사이와 금속 캔/인접 도선의 접촉이 없다. 특히 캔이C라는 사실을 단순한 장식이 아니라 연결 위험과 충돌 검토에 반영한다.
4. 보드의 접점·홀 구조, 삽입 깊이와 몸체 높이를 실제 부품에 대조한다. 보드에 억지로 눌러 끼우는 단계로 구현하지 않는다.
5. 확인 전 상태는 `성형 조건 확인 필요`로 남기고, 원형 부품의 기본 자동 삽입과 구분한다. 이 확인은 사용자가 원하는 설계 기능에 대한 승인 절차가 아니라 **입력 부품의 실제 물리 조건**이다.

현재는 위 조건의 실물 검증 근거가 없으므로 이 패턴을 카탈로그의 기본 `direct`로 등록하지 않는다. 소켓/납땜 어댑터도 실제 제품·핀·치수가 정해지지 않은 상태에서는 추정 등록하지 않으며 이번 범위를 확장하지 않는다.

## 현재 엔진에서 필요한 변경 — 추후 구현 설계

현재 `engine.ts`의 `three`는 세 핀을 한 행의 연속 열에 놓고, `Breadboard.tsx`는 모든 transistor/mosfet을 TO-92 모양으로 그린다. 따라서 `external→direct` 한 줄 변경만으로는 정확한 BC109C 지원이 될 수 없다.

| 변경 위치 | 추후 최소 변경 내용 | 이유 |
|---|---|---|
| `ComponentDefinition`/카탈로그 | 전기적 품번·핀맵과 별개인 `physicalProfile` 식별자 및 `conditional` 상태 | 부품이 BC109C라는 사실과 성형된 형태라는 사실을 분리 |
| `footprint()` | 일반3핀과 구분되는 명시적 TO-18 성형 프로필만 허용 | 다른 모든TO-18/3핀 소자로 규칙이 퍼지지 않게 함 |
| `candidatePlacement()` | 허용한 세 열·두 행 좌표를 사용 | 한 연결 열에 두 전극이 들어가는 단락 방지 |
| `nominalPlacementMatches()` | 세 핀을 첫 핀 행으로 강제로 맞추는 현행 로직을 우회 | 현행 로직은 삼각형을 직선으로 바꿔 버림 |

| `createAssemblySteps()` | 탭방향·핀1E/2B/3C·정확한홀·캔=C·성형조건을부품삽입단계에표시 | 색/번호만보고TO-92처럼꽂는실수를방지 |

조건부프로필을 새 definitionId로 제공할지, 기존 definitionId에 별도의 장착설정을 붙일지는 이후 구현에서 결정한다. 어느 방식이든 **원래 `bjt-bc109c-philips-to18`의 현재 저장 프로젝트를 조용히 새 성형 배치로 바꾸지 않는다.**

## 구현 시 필요한 검증 사례

- 원래TO-18 피치 좌표는 무성형2.54격자로 배치 성공하지 않는다.
- 조건부프로필을 선택하지 않은 원품은 외부연결필요 상태를 유지한다.
- E/B/C 세 홀은 서로 다른 전기 연결그룹이고 핀번호와net가 유지된다.
- 잘못된 미러링,두전극동일열,핀하나만이동,중앙골/보드경계넘김은 거부한다.
- 같은 프로필의 평행이동·복사·저장/복원은 형상과핀매핑을 유지한다.
- 금속캔과탭의 표시·예약공간은 제조사치수에대응하며핀hover에정확한E/B/C·홀이보인다.
- 조립안내와내보낸그림에서 `성형조건부` 표시가 사라지지 않는다.
- 회로해석성공은 물리배치검증이나실물성형확인을 대신하지 않는다.

현재 지원범위표에는 Lab2/Lab5/P25/P22/P23의 **BC109C 실물 배치 미완료**를 계속 남긴다. 이번 조사로 해결한 것은 정확한 장벽과 구현 조건의 식별이며, 실제 부품이 그림 그대로 꽂히는 프로필의 완료가 아니다.
